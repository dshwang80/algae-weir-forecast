# ABC probe 2차 비교: LightGBM vs Ridge (v6 abc 규약, npz 게이트 재사용)

- 입력: probe/abc_H7.npz / abc_H3.npz (sha256 게이트 검증 통과 — 243c4c0d… 원본 그대로, 미변경)
- 러너: probe/lgbm_probe.py (LGBMRegressor, seed=7, n_jobs=1, deterministic)
- 판정 규약: native = 전체 train(≤2023) 학습 → 각국 test; LOSO = 각국 drop 후 학습 → 그 국 test. RMSE_log.
- 파라미터: P0 = leaves 31·n_est 400·min_data 20·feature_frac 0.8, P1 = leaves 15·n_est 300·min_data 30, P2 = leaves 63·n_est 600·min_data 10 (lr 0.05 공통)

- ASOS(B): 두 모델 모두 16국 LOSO 평균 기여 |Δ|≤0.017 수준(미약). Ridge의 wx16 native 최대 기여(perm +0.535·native B−C −0.004 내지 개별국 집중)는 LOSO에서 사라짐 — ASOS 과적합은 모델 간/국가 간로 재배치됨.

- 상주 개선 확대(−0.040 → −0.165), 구미 LGBM 이득 큼.

## H3(152 test행) 해석

- 두 모델 모두 수문/ASOS 이득 없음: Ridge A−C +0.017·B−C +0.042 / LGBM A−C +0.087·B−C 0.000.
- per-station n≤16이라 국별 변동은 noise 수준 — LGBM 세종 H3는 C 1.307 / B 1.084(−0.223)로 역방향 변동 포함.

## 결론(논문 서사 초안)

1. 세종(3012A07) +0.167 예외 = ASOS 매핑 불일치(대전 133 교체 불변)도 관측 개시 아티팩트도 아닌, **hy_lg_V7(자기 보 게이지 수위) 단독 원인** — test에서 학습분포 하단 고착(μ=−0.86·P95=−0.59·−3sd 15행) + corr 부호 반전(+0.135→−0.049), 폭주행 15/86에서 y 수백 vs 예측 0~10. 소거: +V7 단독 1.338→1.499(+0.161/총 93%), +Q7·I7 0, +tau7 +0.064.
2. 수문(hy) 특징은 LOSO 규약에서 LGBM에서만 확정 이득(A−C −0.023 H7 P1) — 선형(Ridge)에서는 이득 +0.005 이내로 소실. 수문 정보의 이득은 비선형 균열이 잡는다.
3. ASOS(wx16) 19개는 두 모델 16국 LOSO 평균 기여 |Δ|≤0.017 — native 최대 기여("+0.535" perm)는 LOSO에서 과적합 재배치(세종 Ridge → 여주 LGBM)로 변질. ASOS 이득 주장은 지점별 검증 없이 등재 불가.
4. LGBM 파라미터 민감 — 강한 정규화(P1)에서 기준선 대비 전 행 이득. 제출 규약은 P1(leaves 15·n_est 300·min_data 30) 권장.
